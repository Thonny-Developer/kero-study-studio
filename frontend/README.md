# Vibely — фронтенд

Учимся вайбкодингу и маркетингу с AI по 5 минут в день. Это кликабельное приложение в духе Duolingo: путь из уроков, сердечки, стрик, XP, лига и AI-песочница, где промпт оценивает Mistral.

**Стек:** Vite, React 19, TypeScript, Tailwind 3, Framer Motion, Zustand. Данные и игровая логика живут на бэкенде в [`../backend`](../backend/README.md). Фронт хранит в браузере только токен, тему, текущий экран и черновик ответа.

## Запуск

Нужны два терминала:

```bash
# 1. бэкенд
cd backend && npm install && cp .env.example .env   # вставь MISTRAL_API_KEY
npm run dev                                         # http://localhost:8787

# 2. фронт
cd frontend && npm install
npm run dev                                         # http://localhost:5173
```

Vite проксирует `/api` и `/p` на `http://localhost:8787`. Если бэкенд на другом адресе, задай `BACKEND_URL` в `frontend/.env`.

С телефона в той же сети открой `http://<IP-ноутбука>:5173`: приложение запустится на весь экран.

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер |
| `npm run build` | проверка типов и сборка в `dist/` |
| `npm run preview` | посмотреть сборку |

## Деплой на Vercel

Сначала задеплой бэкенд (см. [backend/README.md](../backend/README.md#деплой)) и возьми его адрес.

1. В Vercel: **Add New → Project**, импортируй репозиторий.
2. **Root Directory** = `frontend`. Framework Preset определится как **Vite**.
3. Environment Variables: `VITE_API_URL=https://<адрес-бэкенда>`.
4. Deploy.
5. Адрес фронта пропиши в `CORS_ORIGIN` у бэкенда и передеплой бэкенд.

## PWA

В проекте есть манифест, иконки 192/512/maskable, apple-touch-icon и service worker (только в проде; `/api` он не кэширует). Открой сайт на телефоне и выбери «На экран „Домой“».

│                Project, League, Profile
├─ store/game.ts UI-состояние и вызовы API

Дизайн-токены (цвета треков, радиусы, «нажимаемые» тени) лежат в `tailwind.config.ts`, значения цветов для светлой и тёмной темы — в `src/index.css`.

## Как всё устроено

- **Флоу:** приветствие → онбординг (цель, уровень, минуты, имя, почта и пароль) → подтверждение почты кодом из письма → карта → урок с фидбеком на каждый ответ → конец урока → карта с открытым следующим узлом.
- **Аккаунт привязан к почте:** вход по имени или почте с любого устройства, «Забыли пароль?» присылает код на почту, в профиле видно статус почты, её можно сменить или подтвердить. Кнопка в письме возвращает в приложение (`/?verified=1`).
- **Проверка ответов** на сервере. Правильный ответ и разбор приходят только после «Проверить».
- **Сердечки:** ошибка отнимает одно, песочница — нет. Одно сердечко восстанавливается за 10 минут, таймер считает сервер. При 0 можно подождать или повторить урок.
- **XP:** 10 за верный ответ, в песочнице — по оценке AI. Сверху +5 за урок, +15 без ошибок, +15 за квест дня и +50 за первый проект юнита.
- **Стрик** считается по календарным дням в твоей таймзоне.
- **Лига** — реальные зарегистрированные пользователи, места пересчитываются по XP за неделю.
- **Проекты:** промпт из финальной песочницы юнита выполняет Mistral (лендинг, код бота или тексты). Результат показывается в приложении и доступен по публичной ссылке `/p/:id`.
- **Перезагрузка** ничего не ломает: текущий урок хранится на сервере.

Контент уроков (2 юнита на трек, в каждом 3–4 урока и проект, по 5 заданий) лежит в `backend/src/content/lessons.ts`.
